# Changelog

## [0.1.0] - 2026-09-17
### Initial Publication Release
- Release of the frozen 3-seed ensemble (`phase10r` and `phase16_brain`).
- 105-feature external-only Ridge canonical body-frame alignment.
- Multi-scale PointNet++ encoder with 320 surface memory tokens.
- Target-query cross-attention decoder across 121 anatomical structures.
- Support for .PLY, .PCD, .OBJ, .STL, .XYZ, .TXT, and .NPY.
- Fully typed public API (`predict`, `predict_multiple`, `predict_all`, `predict_batch`).
- Full CLI tool suite (`surface2anatomy`).
