--------------------------------------------------

--------------------------------------------------

For every target k and surface region r:

run inference with region r removed.

Define:

    A[k,r]
      =
      MRE_k(mask region r)

Interpretation:

    A_norm[k,r]

12. NEW METHODOLOGICAL CONTRIBUTION #3
COVERAGE-CONDITIONED TARGET QUERY DECODER
======================================================================

Now use the observability concept inside the model.

Call the method:

    Coverage-Conditioned Target Query
    CCTQ

Do not make an unnecessarily huge architecture.

Keep the encoder mostly fixed.

For each surface compute visibility vector:

    v ∈ [0,1]^12

where v_r is fraction of expected surface support visible in region r.

Learn:

    E_target(k)
    E_region(r)

and a target-region affinity matrix:

    O ∈ R^(121 x 12)

Use coverage in query formation:

    q'_k =
      q_k
      +
      MLP(
          O_k ⊙ v
      )

Optionally also bias cross-attention logits:

    attention_bias(k,m)
      =
      β * O[k, region(m)] * v[region(m)]

where:

region(m)
=
surface region containing token m.

The network is therefore explicitly aware of:

    WHICH TARGET IS REQUESTED
    +
    WHICH EXTERNAL REGIONS ARE ACTUALLY VISIBLE

This must be ablated rigorously.
